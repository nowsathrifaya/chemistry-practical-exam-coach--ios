================================================================================
SINGAPORE GCE O-LEVEL CHEMISTRY (6092) — REVISION MATERIALS PACK
For use with the Chemistry Practical Exam Coach app
================================================================================

This pack contains research-backed revision materials for Paper 3 (Practical)
content, formatted as plain text (.txt) so they can be easily copied into the
app's Study Notes, ACE Question Bank, and reference material modules.

FILES IN THIS PACK:

01_qualitative_analysis.txt
  - Complete cation tests (NaOH, NH3): Ca2+, Cu2+, Fe2+, Fe3+, Zn2+, Al3+,
    Pb2+, NH4+
  - Complete anion tests: CO3 2-, Cl-, Br-, I-, SO4 2-, NO3-, PO4 3-
  - Complete gas tests: H2, O2, CO2, NH3, Cl2, SO2
  - Flame test colours: Li, Na, K, Ca, Ba, Cu
  - Indicators: methyl orange, phenolphthalein, Universal Indicator
  - Common QA mistakes

02_solubility_and_salts.txt
  - Full solubility rules table
  - Salt preparation decision tree (precipitation, excess method, titration)
  - Worked examples for each method
  - Common salt preparation errors

03_titration_calculations.txt
  - 5 fully worked titration calculation examples
  - Burette technique and concordant titre rules
  - Common titration errors

04_electrolysis.txt
  - Molten vs aqueous electrolysis rules
  - Selective discharge rules (cathode & anode)
  - 5 worked examples (CuSO4, dilute/concentrated NaCl, H2SO4, Al2O3)
  - Half-equation writing rules
  - Common electrolysis mistakes

05_energy_changes.txt
  - Exothermic vs endothermic
  - Bond energies (breaking = endothermic, making = exothermic)
  - Energy level diagrams
  - Calorimetry: q = mcΔT worked example
  - Experimental procedure and error sources

06_rate_of_reaction.txt
  - Factors affecting rate (temperature, concentration, surface area, catalyst)
  - Three measurement methods (gas volume, cross disappearing, mass loss)
  - Full planning framework with sample model answer
  - Rate calculation worked examples
  - Common mistakes

07_yield_purity_water_crystallisation.txt
  - Water of crystallisation calculation method + worked example
  - Percentage yield formula + 2 worked examples
  - Percentage purity formula + worked example
  - Common calculation mistakes

08_separation_techniques.txt
  - All 8 separation methods (filtration, crystallisation, evaporation,
    simple/fractional distillation, separating funnel, sublimation,
    chromatography)
  - Decision guide for choosing the right method
  - Common mistakes

09_mock_exam_questions.txt
  - 5 full mock questions in Paper 3 style with complete worked answers:
    Q1 Titration (12 marks), Q2 Qualitative Analysis (10 marks),
    Q3 Planning - Rate of Reaction (6 marks), Q4 Energy Changes (7 marks),
    Q5 Water of Crystallisation (5 marks)

10_study_notes_expanded.txt
  - Expanded notes covering all 12 syllabus topics:
    Experimental Design, Separation, Acids/Bases/Salts, Redox,
    Atmospheric Gases, Atomic Structure & Stoichiometry, Bonding,
    Energetics, Chemical Reactions, Electrolysis, Organic Chemistry,
    Periodic Table

--------------------------------------------------------------------------------
HOW TO USE THIS WITH YOUR APP
--------------------------------------------------------------------------------

1. QA Simulation Module — use 01_qualitative_analysis.txt to expand from
   3 tests to the full set of cation/anion/gas tests.

2. Study Notes Module — use 10_study_notes_expanded.txt to expand your
   ~15 notes to cover all 12 topics with more depth.

3. ACE Question Bank — use 09_mock_exam_questions.txt and the worked
   examples in files 03, 04, 05, 06, 07 as templates to generate more
   than the current ~40 questions. Each worked example can become 2-4
   ACE-style questions by varying numbers.

4. Reference Materials (currently missing in app) — files 01 and 02
   contain the solubility rules, flame test colours, and indicator tables
   that should be added as an in-app "Notes for Qualitative Analysis"
   reference screen (matching what SEAB provides in the real exam).

5. Calculation Practice Module (currently missing) — files 03, 05, and 07
   provide the exact formulas and worked examples needed to build titration,
   calorimetry, and water-of-crystallisation calculators/quizzes.

6. Salt Preparation Simulation (currently missing) — file 02 gives the
   step-by-step procedures for all three salt preparation methods, which
   can be turned into an interactive simulation similar to the existing
   electrolysis one.
